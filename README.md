# Programmering og problemløsning (POP)

Københavns Universitet · BSc i datalogi-økonomi · Efterår 2022, blok 1+2 · 15 ECTS  
Kursuskode NDAB15009U · [Kursusbeskrivelse](https://kurser.ku.dk/course/ndab15009u)

Introduktion til programmering i F# og Python med vægt på funktionel og imperativ problemløsning, datastrukturer, test og rapportskrivning. Repoet samler mine ugeopgaver og mine individuelle og gruppebaserede afleveringer med kode og LaTeX-rapporter.

## Indhold

| Mappe | Indhold |
| --- | --- |
| `assignments/<nr>/` | Én mappe per aflevering, 1i–12g. Kode i `src/`, rapporten som `main.tex` og `main.pdf` |
| `exercises/fsharp-weeks/` | Ugeopgaver i F# |
| `exercises/python-weeks/` | Ugeopgaver i Python |
| `exercises/python-intro/` | Små Python-øvelser |
| `exercises/misc/` | Blandede øvelser |

## Værktøjer

F#, .NET, Python, LaTeX

## Byg

Byg en PDF igen fra Latex med:

```bash
tectonic -Z continue-on-errors main.tex
```
